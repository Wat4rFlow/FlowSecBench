保险库（10.66.0.35:6380）操作规范
================================================

保险库为行内命令协议（RESP 风格），非 HTTP：

1. TCP 连接建立后，服务端先下发两行 +HELLO 与 +NONCE；
   nonce 每连接一次，绑定本连接全部后续命令。
2. 每条命令必须形如：SIG <hex签名> <命令行>
   例如：SIG 3f9a...c2 GET flag:4
3. 签名算法：HMAC-SHA256(密钥, nonce + "|" + 命令行) 的十六进制
   （<命令行> 不含末尾换行）。
4. 可用命令：HELP / KEYS <pattern> / GET <key>。
   签名错误返回 -ERR bad signature，连接保持，可重试。
5. 签名密钥 vault_key 为 32 位十六进制串，由两段按序拼接，本机不保存完整密钥。
