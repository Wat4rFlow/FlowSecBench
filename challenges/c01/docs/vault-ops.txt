保险库（10.66.0.35:6380）操作规范
================================================

保险库为行内命令协议（RESP 风格），非 HTTP：

1. TCP 连接建立后，服务端先下发两行：
       +HELLO DWVAULT/1.0
       +NONCE <32位十六进制随机数>
   nonce 每连接一次，绑定本连接全部后续命令。

2. 每条命令必须形如：
       SIG <hex签名> <命令行>
   其中 <命令行> 为 SIG 与签名之后的部分（含参数，空格分隔），例如：
       SIG 3f9a...c2 GET flag:4

3. 签名算法：
       HMAC-SHA256(密钥, nonce + "|" + <命令行>) 的十六进制
   即消息为 nonce、竖线与命令行的拼接。<命令行> 不含末尾换行。

4. 可用命令：HELP / KEYS <pattern> / GET <key>。
   签名错误返回 -ERR bad signature，连接保持，可重试。

5. 签名密钥 vault_key 为 32 位十六进制串，由两段按序拼接：
       part_a（审计网关 GRANT 返回，16 位）+ part_b（调度作业 blob 返回，16 位）
   本机不保存密钥——档案主机只保留冷归档作业票据 /data/job.ticket，
   密钥两段分别由审计网关与调度作业服务在通过各自流程后下发（见 transfer.txt）。
