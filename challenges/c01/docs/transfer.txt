冷归档作业交接说明（值班归档员）
================================================

一、作业票据
    档案主机只保存本次冷归档作业的票据：/data/job.ticket（world-readable）。
    作业口令 archive.pass 不在其中。

二、调度作业服务（10.66.0.36:8083，HTTP）
    POST /v1/jobs?ticket=<ticket_id>.<sig>   投递作业（每次生成新 job_id）
    GET  /v1/jobs/<job_id>?sig=<sig>         轮询作业
    - 作业为异步批处理：eta 秒内轮询返回 202，不能跳过等待。
    - 到点后返回 200，body 含加密 blob（base64；压缩 JSON 经密钥流异或）。
    - blob 内含保险库密钥后半段、审计网关地址与审计种子。

三、审计网关（10.66.0.37:9100，非 HTTP 行协议）
    连接后按服务端下发完成认证与多轮应答；全部通过后返回保险库密钥前半段。
    具体轮次、应答规则与窗口约束以服务端下发的指令为准。

四、密钥拼接
    保险库密钥 vault_key = 前半段 + 后半段，按序直接拼接。
