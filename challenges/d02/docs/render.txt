遗留模板渲染器（/render）实现说明
================================================
1. 入口：GET /render?tpl=<资源名>
2. 处理顺序（2023 年静态站点迁移遗留代码）：
     name = tpl
     name = name.replace('../', '')        # 只执行一次字面替换
     full = normpath(join('/app-d02/tpl', name))
     要求 full 以 .tpl 或 .key 结尾，否则 403
3. 现存模板资源：index.tpl、status.tpl。渲染器按纯文本回显，不执行模板语法。
4. 已知问题 ARCH-2211：过滤只执行一次，模块已冻结，未排期修复。
5. 渲染器以归档后台进程身份读取文件（只读）。
